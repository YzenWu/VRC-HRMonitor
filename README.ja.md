# HeartRateMonitor

VRChat 向けリアルタイム BLE 心拍ツール：OSC 経由で心拍数とハードウェアテレメトリをチャットボックスへ送信——フローティングウィンドウ、リモート Web フロントエンド、CLI/TUI、VRChat ツールキットを備えたオールインワンの Windows アプリ。

## 機能

### BLE 心拍デバイス

- 標準的な Bluetooth Low Energy 心拍デバイス（Heart Rate Service `0x180D`）に対応——チェストストラップ、スマートバンド、スポーツウォッチ。
- **マルチデバイス対応**：複数のセンサーを同時接続。上限は Bluetooth スタックとハードウェア次第。
- スマートなデバイスのスコアリングと並び替え、別名、自動再接続、弱信号（RSSI）警告、デバイスごとのフローティングウィンドウ。
- 自動検出：重み付けに従って候補デバイスを順次接続し、オーディオ / スマートホーム機器や心拍特性を持たないデバイスは自動的にスキップ。

<img src="images/hrcurve.png" alt="心拍曲线">

### VRChat OSC チャットボックス送信とライブプレビュー

- 自由な `{変数}` テンプレートで「心拍数 + CPU / GPU / メモリなど」を OSC/UDP 経由で VRChat のチャットボックス（`/chatbox/input`）へ送信。
- 編集中は毎秒更新されるテンプレートのライブプレビュー。文字数カウンタ付きで、チャットボックスの 144 文字上限に近づくと警告（送信はブロックしない）。
- カスタム OSC 送信（任意アドレス / テキスト）、Webhook 送信、OSC 受信（ポート 9001）による VRChat アバターパラメータの監視、「起動時に自動送信」オプション。

### フローティングウィンドウ

- 現在の BPM（または画像）を表示する最前面のデスクトップウィジェット。メインウィンドウ 1 つ + デバイスごとに 1 つ。
- ロックしてクリック透過、DPI 対応のリサイズ、ウィンドウごとの位置・サイズを個別に保存。
- ウィンドウごとにデータソース（平均または特定デバイス）と更新間隔を設定可能。

<img src="images/overlay.png" alt="フローティングウィンドウ" width="500">

### ハードウェアテレメトリ変数

- レジストリ、WMI、PowerShell、`systeminfo` で Windows ホスト情報を収集。CPU / メモリ / GPU / VRAM 使用率、温度、ディスク、コミットなどリアルタイム指標は PDH から取得（タスクマネージャーと同ソース）。
- すべてがテンプレート変数に：`{CPU_USAGE}`、`{RAM_PERCENT}`、`{TIME_ISO}`、NTP 時刻……さらにカスタム変数（四則演算 / 連結 / 正規表現 / コマンド出力）、変数ごとのリネーム / 上書き / 単位。
- `CPU_USAGE_VRCHAT`、`MEM_USAGE_<名前|PID>`、`USAGE_FILE_<パス>` などの動的プロセス変数。

### ヘルスステータス

- 安静時心拍のキャリブレーションと閾値係数からステータス（睡眠 / 安静 / 活動 / 興奮）を推定し、OSC 姿勢パラメータ（AFK / 着席 / 移動速度）にも反応。
- `{HEALTH_STATUS}` 変数として公開され、送信テンプレートでそのまま使用可能。

### 記録とエクスポート

- 心拍、OSC トラフィック、ヘルスステータス、ハードウェアスナップショットをローカル SQLite に記録。日次 JSONL / CSV バックエンドも選択可能。
- 5 種類の記録（アバター変更、VRChat セッション、デバイス接続、心拍詳細、ハードウェアスナップショット）をカテゴリごとの保持日数付きで管理。
- 統計ページ（最小 / 平均 / 中央値 / 最大 / 標準偏差、トレンド、ヒストグラム、デバイス別、OSC アドレス Top-N）は期間選択に対応し、TXT / JSON / YAML / CSV へエクスポート可能。

### リモート Web セカンドフロントエンド（LAN/WAN 階層 + HTTPS）

- 同一 UI を同一ポート（デフォルト 9460）でネットワーク内のスマートフォンやタブレットに提供。
- 接続元による階層化アクセス：ループバック接続はローカル管理者（ログイン不要）。LAN からの接続はリモートスイッチとローカルアカウントが必要。WAN（外部）からの接続はさらに WAN スイッチが必要——管理者の強力なパスワードと明示的なリスク確認ダイアログが求められる。
- ロール（admin / user）ごとのセクションホワイトリスト、PBKDF2 パスワード保存、UA 紐付けセッションとアイドルタイムアウト、監査ログ、証明書サムプリントによるオプションの HTTPS。

### CLI / TUI

- `hrmcli.exe`（`HeartRateMonitor.exe --cli` と完全同等）：スクリプト用のワンショットコマンド、プレーン REPL（`--shell`）、デフォルトでは TestDisk 風のメニュー TUI。
- デバイス、OSC、送信テンプレート、ハードウェア変数、ヘルス、記録 / エクスポート、Web / リモート、UI 設定、フローティングウィンドウ、ログを網羅する約 40 コマンド——アプリ内コンソールタブと同じコマンドエンジンを使用。

### Toolkit

サイドバー左下のドックから VRChat ツールキットを開きます：

- **設定ファイルエディタ**——VRChat `config.json` の主要フィールドをテーブル編集、厳格な JSON 型検証付き。
- **ログブラウザ**——VRChat ログの一覧 / 閲覧 / 検索。
- **キャッシュクリーナー**——キャッシュ使用量の分析とクリーンアップ。ドライランプレビューと確認フレーズ付き。
- **写真インデックス**——写真ライブラリの並列インデックス化とキーワード検索（VRChat スクリーンショットの XMP メタデータ）。
- **ゲーム統計**——プレイ時間 / 心拍 / ハードウェアデータの集計統計とグラフ。
- **プロセス分析**——VRChat プロセスの CPU / メモリスナップショット。

### セーフモード

- `--safemode`（または設定画面 / R 三回入力）で自動接続、自動検出、自動再接続、OSC 送信、ハードウェア収集などすべての自動処理を一時停止し、トラブルシューティングを支援。有効中は常時バナーが表示され、ワンクリックで通常再起動できます。

### UI：10 言語とテーマ

- 界面は 10 言語に対応：繁體中文 / 简体中文 / 繁體中文（香港） / 粵語（香港） / English / 日本語 / Español / 한국어 / Deutsch / Français。CLI とログも同じ言語に追従。
- ライト / ダークモード × カラーパレット（デフォルト / フォレスト / サンセット / オーシャン / バイオレット / **単色カスタムモード**でアクセント・背景・パネル色を自由設定）、角丸と密度のスライダー、システムテーマ追従、グローバルアニメーションスイッチ。
- レイアウト設定（カード順序、列幅、曲線パラメータ……）はローカル保存に加えてバックエンドへミラーされ、再インストール後も失われません。

## 動作環境

- Windows 10 または 11、64 ビット（x64）。
- Microsoft Edge WebView2 ランタイム（ほとんどのシステムにプレインストール済み。無い場合は Microsoft の Evergreen ランタイムをインストール）。
- Bluetooth Low Energy 対応のアダプター（内蔵または USB ドングル）。
- 任意：フレームワーク依存ビルドには .NET 10 ランタイムが必要——スタンドアローンビルドは自己完結型です。

## ビルド済み ZIP からの利用

1. [Releases](https://github.com/yzenwu/VRC-HRMonitor/releases) から最新の `HeartRateMonitor-*-x64.zip` をダウンロードし、任意の場所に展開します。
2. `HeartRateMonitor.exe`（または `hrm-webui.exe`）を実行すると、エンジンがシステムトレイに入り、スプラッシュ画面とともに WebView2 ウィンドウが開きます。
3. 初回起動時に設定はデータディレクトリ `%AppData%\HeartRateMonitor` に書き込まれます（ログ、エクスポート、データベースも同じ場所。実行ファイルの横に `data_location.txt` を置けばリダイレクト可能）。
4. スキャンを開始し、BLE センサーを接続、OSC 送信を有効化して VRChat に入ると、チャットボックスが更新され始めます。
5. `hrmcli.exe` はターミナル版。`hrmdump.exe` はクラッシュウォッチドッグとして自動実行されます。
6. スマートフォンからのリモートアクセス：リモートスイッチ（Web タブ）を有効化し、同じネットワークのスマートフォンで `http://<PC-IP>:9460/webui/` を開いてローカルアカウントでログインします。

## ソースからのビルド

> このリポジトリはプロジェクトのソーススナップショットです。

必要なもの：

- **gcc（MinGW-w64）**——C 言語 OSC エンジン（`Engine/`）のコンパイル。
- **.NET 10 SDK**——4 つの C# 実行ファイル（`HeartRateMonitor.exe`、`hrm-webui.exe`、`hrmcli.exe`、`hrmdump.exe`）の発行。
- **Node.js + npm**——Vue 3 フロントエンド（`WebUI/`）のビルド。

リポジトリルートでビルド（PowerShell）：

```powershell
./build.ps1 --releases     # フレームワーク依存リリース + ZIP
./build.ps1 --debug        # デバッグビルド：コンソール + 詳細ログ
```

スクリプトは C エンジン、Web フロントエンド（vite）、4 つの .NET プロジェクトを順にビルドし、`Built/<ブランチ>-<タイムスタンプ>/` に出力します。リリースビルドでは SHA-256 サイドカー付きの `HeartRateMonitor-*-x64.zip` も生成されます。`Release.json` はリリースメタデータ（バージョン、アイコン、リポジトリ、ビルド時刻、ライセンス）の単一ソースで、ビルド時に実行ファイルへ埋め込まれます。2 つのビルドを並行実行しないでください（中間 `obj/` ディレクトリを共有します）。
